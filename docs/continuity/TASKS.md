# Cola propuesta — no son órdenes de implementación

Antes de tomar una tarea, obtener autorización y completar ficha. Las prioridades
evitan invertir las cuotas restantes en contenido nuevo sin consolidar bases.

| Prioridad/tarea | Dueño apropiado y alcance | Dependencias / salida |
|---|---|---|
| P0 publicar documentación recuperada | Agente con Git local; sólo diez archivos documentales/herramientas | Commit local autorizado; push requiere confirmación; B+C1 ya publicado/verificado |
| P0 preparar diff C2 provisional | Agente con Git local; Resource, informes y fixtures correspondientes | Sólo después de cerrar fase documental; propuesta independiente, sin commit/integración/publicación automática |
| P1 revisión documental independiente | IA revisora, sólo lectura | Contrastar STATUS con commit; detectar afirmaciones heredadas/no implementadas |
| P1 plan Android B+C1 sin C2 | Usuario/dispositivo; agente prepara sólo al autorizarse | Base exacta2e6e669; seeds65001/65003; no generar ZIP hasta revisión documental/C2 |
| P2 Android calibración C2 | Usuario/dispositivo; entrega separada tras aprobación | No incluir C2 incidentalmente en el primer paquete B+C1 |
| P2 búsqueda en otros módulos | Agente Godot; fixtures sólo en primera etapa | Base recuperada con radio2.0; no retocar IA/nav/percepción antes de evidencia |
| P2 inspección angular tras puntos | Diseño/revisión, no implementación automática | Sólo si radio2.0 resulta insuficiente; límite temporal, sin posición oculta |
| P2 roadmap narrativo mínimo | IA de arquitectura, sólo especificación | Auditoría Phase1; no afirmar guardado/rig/reproductor existente |

Reservar por archivo, no por nombre de IA. Revisión de documentos, QA Android y
lectura de arquitectura pueden ser paralelas al desarrollo siempre que no
escriban los mismos sistemas. La tabla no asigna cuotas ni garantiza planes gratis.

NATIVE_SHUTDOWN_AV, Safe save failed, caché NavMesh rechazada, solver Horvex y
balance de enemigos no se convierten en tareas activas por estar en la cola.
El usuario decide el orden y autoriza cada expansión de alcance.
